# Нейро-чат

**Нейро-чат** — AI-нейросеть с ассистентом **Нейро**.

## Возможности

- 🤖 AI-ассистент Нейро
- 🌓 Тёмная, светлая и системная тема
- ✨ Стеклянный интерфейс
- 📱 Адаптация под разные устройства 
- 💾 Сохранение данных в браузере
- ⚙️ Настройки интерфейса
- ☁️ Cloudflare Workers
- 🧠 Cloudflare Workers AI

## Структура

- `index.html` — интерфейс
- `worker.js` — серверная часть и API
- `wrangler.jsonc` — конфигурация Cloudflare
- `package.json` — настройки проекта
- `.gitignore` — исключения Git

## Запуск

```bash
npm install
npm run dev
