# Нейро-чат

**Нейро-чат** — современная AI-платформа с интеллектуальным ассистентом **Нейро**, созданная для общения, работы с информацией и удобного взаимодействия с искусственным интеллектом.

## Возможности

- 🤖 **AI-ассистент Нейро** — общение с искусственным интеллектом
- 🌓 **Тёмная, светлая и системная тема** — настройка интерфейса под ваши предпочтения
- ✨ **Стеклянный интерфейс** — современный дизайн с эффектом Glassmorphism
- 📱 **Адаптация под разные устройства** — удобная работа на смартфонах, планшетах и компьютерах
- 💾 **Сохранение данных в браузере** — ваши настройки и данные сохраняются между сеансами
- ⚙️ **Настройки интерфейса** — персонализация внешнего вида и работы приложения
- ☁️ **Cloudflare Workers** — быстрая и надёжная серверная инфраструктура
- 🧠 **Cloudflare Workers AI** — использование искусственного интеллекта непосредственно через инфраструктуру Cloudflare

## Структура проекта

- `index.html` — пользовательский интерфейс и клиентская часть
- `glass.css` — стили и оформление интерфейса
- `worker.js` — серверная часть, API и взаимодействие с AI
- `wrangler.jsonc` — конфигурация Cloudflare
- `site.webmanifest` — настройки веб-приложения и PWA
- `package.json` — настройки проекта и зависимости
- `.gitignore` — список файлов и папок, исключённых из Git
