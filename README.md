# Нейро-чат 🤖

**Нейро-чат** — современный AI-чат с тёмным интерфейсом, несколькими AI-моделями и дополнительными инструментами для работы с изображениями, видео, музыкой, 3D-моделями и сайтами.

## ✨ Возможности

- 💬 Общение с AI
- 🧠 Выбор AI-модели:
  - Нейро
  - ChatGPT
  - Gemini
  - Grok
  - Алиса 1
- 🖼️ Создание изображений
- 🎬 Создание видео
- 🎵 Создание музыки
- 🧊 Создание 3D-моделей
- 🌐 Создание сайтов
- 📎 Загрузка файлов
- 🎙️ Голосовой ввод
- 💾 Сохранение истории чатов
- 👤 Регистрация и авторизация
- ⚙️ Настройки пользователя
- 🔐 API-ключи провайдеров
- 🕶️ Временные чаты
- 🔌 Управление подключёнными сервисами
- 📱 Адаптация под iPhone, iPad и компьютер
- 🌑 Премиальный тёмный интерфейс

## 🧠 AI-модели

В проекте предусмотрен выбор между несколькими моделями:

| Модель | Назначение |
|---|---|
| Нейро | Основной AI проекта |
| ChatGPT | OpenAI |
| Gemini | Google |
| Grok | xAI |
| Алиса 1 | Алиса |

Доступность конкретной модели зависит от подключённого API и настроек сервера.
